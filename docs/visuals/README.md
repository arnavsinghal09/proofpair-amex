# ProofPair visual system

These vector masters explain the same product at three levels:

- `proofpair-product-map.svg` — the operating system and its user-facing surfaces.
- `proofpair-wireframes.svg` — the structural hierarchy of the four demonstration screens.
- `dispute-resolution-flow.svg` — end-to-end work across system and human-authority lanes.
- `decision-control-flow.svg` — verified-evidence, contradiction, abstention, recommendation, and receipt gates.
- `production-event-flow.svg` — the production-target synchronous and asynchronous architecture.

Every production architecture visual is explicitly a target blueprint. Product surfaces and decision controls correspond to the working synthetic prototype.
