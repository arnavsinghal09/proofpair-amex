# Prototype screenshot captions

These captions are written for evaluators. Keep the filename order.

1. **Command center — operational pressure before case detail.** Synthetic workload, SLA exposure, queue state and recent activity establish the analyst’s next action without collapsing the product into a chatbot.
2. **Dispute queue — evidence-aware triage.** Search, saved views, configurable columns, selection and bulk routing support real operating work across ownership, age, reason code and evidence state.
3. **Case overview — one record, both parties.** Transaction facts, narrative, member position, merchant position, chronology and review tasks remain visible in the same case context.
4. **Evidence room — provenance before persuasion.** Required-record coverage, verification state, source detail and contradictions make the basis of the recommendation inspectable.
5. **Decision studio — governed recommendation.** A version-pinned reason pack exposes required evidence, contradiction status, party signal ledger, minimum gap, rationale and receipt controls.
6. **Specialist route — failure is a product state.** When verified records conflict or remain incomplete, ProofPair names the blocker and routes the case without issuing a recommendation or taking account action.

## Screenshot truth note

All names, merchants, cases, evidence and metrics are fictional. Screenshots demonstrate implemented browser-session workflows against synthetic fixtures. External connectors, authentication, persistence, outbound delivery and financial actions are not implemented.
